Executive Course Summary arrow_back_ios_new edited by AI

This course addresses foundational and contemporary abstractions in distributed computation, synchronization paradigms, consensus, fault resilience, and modern hyperscale cloud infrastructures. Students will transition from rudimentary distributed theoretical topologies to auto_awesome formulate and deploy production-grade multi-region decentralized protocols, asynchronous RPC runtimes, and resilient quorum services capable of strictly maintaining partition safety under high concurrency.

Course Goal 1: Theoretical Foundation REVISED

Deconstruct time synchrony, logical vectors, and Lamport causality metrics across globally unsynchronized physical clocks.

Course Goal 2: Practical Implementation REVISED

Architect and bench-test quorum-based write protocols utilizing consensus primitives over real network emulation rings.

04

Course Contents (Modular Syllabus)

5 Core Modules • 42 L Hours
expand_more
MOD 1

Distributed System Models & Logical Time

8 Hours

Architectural models (client-server, peer-to-peer, overlay networks). Physical vs. Logical Clocks, Lamport timestamps, Vector clocks, matrix clocks. Global snapshot algorithms: Chandy-Lamport recording.

#LamportClocks #ChandyLamport #VectorTime
MOD 2

Distributed Mutual Exclusion & Consensus Engines

10 Hours

Ricart-Agrawala, Maekawa quorum algorithm. Leader election (Bully, Ring). The Consensus problem: FLP Impossibility Proof, Paxos state machine consensus, Raft consensus protocol: Leader election, log replication, and joint consensus safety.

#RaftProtocol #Paxos #FLPImpossibility
MOD 3

Fault Tolerance & Distributed Transactions

8 Hours

Failure detectors, Byzantine Generals Problem, PBFT protocol overview. Two-Phase Commit (2PC) and Three-Phase Commit (3PC). Distributed deadlock detection. Quorum-based consistency models.

#TwoPhaseCommit #PBFT #ByzantineFaults
MOD 4

Cloud Infrastructure & Container Orchestration

8 Hours

Virtualization vs Containerization internals (cgroups, namespaces). Cloud service topologies: IaaS, PaaS, Serverless runtimes. Kubernetes architecture: etcd cluster state, kube-apiserver, controllers, and Envoy service mesh ingress controllers.

#Kubernetes #ServiceMesh #Serverless
MOD 5

Large Scale Storage Systems & Data Partitions

8 Hours

Distributed Hash Tables (Chord, Pastry). Consistent Hashing. Google File System (GFS) & Hadoop HDFS architecture. DynamoDB partition ring, virtual nodes, hinted handoff, and read-repair semantics.

#ConsistentHashing #ChordDHT #DynamoTopology
